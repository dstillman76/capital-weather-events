# Capital Weather outdoor source expansion

Validated October 24, 2026 (America/New_York). Starting point: GitHub main commit `ced7771bc953676645b9e8fcd53d27d8868f2446`.

## Result

Five of the twelve investigated sources are integrated. In the live Chromium run, they contributed **17 unique outdoor occurrences representing 13 distinct event titles/series** in the widget's existing October 24–30 window, including today. All five fetch directly across origins; no backend, paid service or new public CORS proxy is involved. Seven sources remain unregistered because the investigation did not establish a reliable browser-accessible path. The [editorial review](capital-weather-editorial-review-2026-10-24.md) rechecked all original 18 occurrences and excluded the mixed indoor/outdoor Countdown program; the confirmed courtyard craft sessions remain with a visible weather contingency.

The source HTML, CSS, established source registrations/parsers, daily tabs, event cards, selection behavior and `cw:event-selected` hourly-forecast integration remain intact. The prior regression runner's default filename referenced a nonexistent file; its default now points to the actual repository widget. The older audit is retained as historical evidence, not presented as a current access test.

## Extraction, accuracy and performance

- CTY requests contain the explicit seven-day range (`MM-DD-YY-to-MM-DD-YY`). The parser requires a current-year header and matches each dated row against the widget's exact dates. It reads a single listing response; no per-event crawl. Shared meridiems such as `12–3 pm` are interpreted as noon–3 p.m.
- Rockville uses explicit API start dates and local times, requests at most three pages of 50, and retains completed pages if a subsequent page fails. All-day entries keep an unconfirmed clock time rather than inventing one. Array-shaped venue data is handled.
- NoMa requires the explicit season year, both bounds, Thursday recurrence and the published time range. Only matching dates inside the season are generated. Post publication/modified timestamps are never used as event dates. Expired seasons produce no occurrences.
- Alexandria supports its literal escaped CRLF transport, standard RFC line folding, escaped punctuation, nested alarms, local floating times and UTC-to-Eastern conversion. Unsupported time zones, invalid dates, canceled/tentative events and unsupported RRULE entries fail closed. This feed currently publishes individual occurrences, with no RRULE records. Multi-day spans are not automatically expanded into invented daily performances. Date-only occurrences display “Time not confirmed.”
- Only titles matched to Alexandria's publisher-generated event index are emitted at runtime. One feed booking URL returned HTTP 404 during link checking; it is no longer the displayed source link. The cemetery tour's Viator URL returned HTTP 403, so its publisher listing is also used. No algorithm guesses event slugs. Woodlawn's physical county is Fairfax County, while its postal city remains Alexandria.
- New-source outdoor screening requires activity-level evidence from the current description or a documented editorial review scoped to source, title and venue. Park names and outdoor-sounding activity titles alone are insufficient. Incidental outdoor seating and parking do not qualify a program. Mixed site-wide indoor programs do not qualify through an outdoor sub-event. Rich-feed reviews require the activity evidence to remain in the current description. Original sources retain their established filtering behavior.
- Exact duplicate publisher records are removed; the existing global title/date/geography deduplicator then runs across old and new sources. Same-URL occurrences on different dates are retained. Four dated Cocktails & Crafts occurrences are separate calendar dates, not four distinct event series.
- New adapters run in a separate **three-worker pool**, with **eight-second request deadlines**, a **1.8 MB response guard**, no retries through third-party proxies, and immediate rendering after each source. Healthy snapshot: **six requests total**; maximum with Rockville's page cap is eight. Legacy source concurrency, detail queue, request paths and timeouts are unchanged.
- The hourly forecast module itself is outside this repository. Its existing `cw:event-selected` integration contract was browser-tested: selection dispatches date, local start/end times, venue/address, city/state/county, coordinates and source URL.

## Established-source availability

No established source was removed, disabled, replaced or routed through a new transport. The latest live snapshot successfully retained Ticketmaster (5 events) and Visit Prince William/ImGoing (9). Several legacy public proxy/source requests timed out (`signal is aborted without reason`) or failed fetches; Reston's existing parser returned no matching cards. These are reported as live access limitations, not silently relabeled as passing integrations. The earlier live run also retrieved Visit Howard County records, showing that these external paths vary between runs.

An additional Chromium run of the untouched `ced7771` widget returned **15 established-source events**. Successful sources were Ticketmaster, Visit Prince William (ImGoing); **16 legacy sources** also reported failures or no matching data in that untouched version. Before editorial revision, the expanded run returned 33 events: the same 15 established-source occurrences plus 18 from the new adapters. The later editorial run contains 17 new records and 14 established-source records (Prince William returned one fewer). This establishes that the observed legacy failures predate this change; it does not guarantee external-source availability on the production host.

## Reproduction and review

The package scripts and dependency lockfile provide reproducible tests. `tests/fixtures/README.md` records fixture endpoints and reductions; no fixture is used at runtime. `work/` is ignored and holds raw research/test artifacts. The source widget is the user-facing deliverable. This change is submitted on a review branch only: **nothing is deployed to the Capital Weather website**.
